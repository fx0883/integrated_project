# CMS前端集成文档

本目录包含CMS系统前端集成相关的文档，帮助前端开发人员理解如何与CMS API进行集成，快速构建内容管理和展示界面。

## 文档目录

1. [CMS系统前端集成概述](./00_cms_integration_overview.md) - 系统架构、认证与授权、API基本信息和集成流程
2. [文章管理前端集成指南](./01_article_frontend_integration.md) - 文章创建、编辑、发布和版本管理
3. [评论系统前端集成指南](./02_comment_frontend_integration.md) - 评论展示、提交、回复和管理
4. [分类与标签管理前端集成指南](./03_category_tag_frontend_integration.md) - 分类树和标签组管理
5. [用户互动与统计前端集成指南](./04_interaction_statistics_frontend_integration.md) - 点赞、收藏、分享和数据统计
