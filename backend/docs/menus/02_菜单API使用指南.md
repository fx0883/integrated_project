# 菜单系统 - API使用指南

## 概述

本文档详细介绍菜单系统的API接口及其使用方法，帮助前端开发人员集成菜单功能。

## 核心API

### 1. 获取路由配置

此API返回当前用户权限下的所有菜单路由配置，是构建动态路由的关键接口。

- **URL**: `/api/menus/admin/routes/`
- **方法**: GET
- **认证**: 需要JWT认证
- **权限**: 已登录用户

#### 响应格式

```json
{
  "success": true,
  "code": 2000,
  "message": "获取路由成功",
  "data": [
    {
      "path": "/dashboard",
      "name": "dashboard",
      "component": "Layout",
      "meta": {
        "title": "仪表盘",
        "icon": "dashboard",
        "rank": 0,
        "showLink": true
      }
    },
    // 更多路由配置...
  ]
}
```

### 2. 菜单管理API

#### 2.1 菜单列表

- **URL**: `/api/menus/`
- **方法**: GET
- **认证**: 需要JWT认证
- **权限**: 管理员
- **参数**:
  - `format`: 可选，值为`tree`时返回树形结构
  - `is_active`: 可选，过滤活动状态

#### 2.2 创建菜单

- **URL**: `/api/menus/`
- **方法**: POST
- **认证**: 需要JWT认证
- **权限**: 管理员

**请求体示例**:

```json
{
  "name": "system_settings",
  "code": "system_settings",
  "path": "/settings",
  "component": "Layout",
  "title": "系统设置",
  "icon": "setting",
  "rank": 100,
  "show_link": true,
  "is_active": true
}
```

#### 2.3 更新菜单

- **URL**: `/api/menus/{id}/`
- **方法**: PUT/PATCH
- **认证**: 需要JWT认证
- **权限**: 管理员

#### 2.4 删除菜单

- **URL**: `/api/menus/{id}/`
- **方法**: DELETE
- **认证**: 需要JWT认证
- **权限**: 管理员

### 3. 用户菜单分配API

#### 3.1 获取用户菜单

- **URL**: `/api/menus/user/`
- **方法**: GET
- **认证**: 需要JWT认证
- **权限**: 用户查看自己的菜单

#### 3.2 管理员分配用户菜单

- **URL**: `/api/menus/admins/{user_id}/menus/`
- **方法**: POST
- **认证**: 需要JWT认证
- **权限**: 管理员

**请求体示例**:

```json
{
  "menu_ids": [1, 2, 3, 4]
}
```

## 错误处理

API可能返回的错误状态码及解释：

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 常见问题

1. **问题**: 菜单无法显示
   **解决**: 检查is_active状态，确认用户与菜单关联正确

2. **问题**: 权限错误
   **解决**: 确认roles字段配置正确且用户角色匹配

3. **问题**: 组件加载失败
   **解决**: 验证component路径正确，组件已正确导出

4. **问题**: 菜单顺序混乱
   **解决**: 确认rank字段设置合理且不冲突
