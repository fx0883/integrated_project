# 客户会员关系展示方案

## 需求分析

根据用户需求，需要在客户管理模块中展示每个客户关联的会员信息。目前系统已有客户列表页面(`/customer/index`)，需要增强该页面以显示客户关联的会员信息。

通过API调用示例可知，系统已有获取客户关联会员的API：
```
GET http://localhost:8000/api/v1/customers/members/relations/customer-members/?customer_id=6
```

该API返回指定客户ID下的所有会员信息，包括会员的用户名、邮箱、电话、昵称等基本信息。

## 现有系统分析

### 相关组件与数据流

1. **客户列表页面**：`src/views/customer/index.vue`
   - 当前实现了客户的列表展示、搜索、分页等功能
   - 提供了查看详情、编辑、删除等操作

2. **客户详情页面**：`src/views/customer/detail.vue`
   - 使用标签页展示客户的基本信息、联系人、租户关系等
   - 已有联系人(会员)关系的展示逻辑，但在单独的标签页中

3. **客户Store**：`src/store/modules/customer.ts`
   - 实现了客户数据的状态管理
   - 包含获取客户会员关系的方法：`fetchCustomerMemberRelations`

4. **客户API**：`src/api/modules/customer.ts`
   - 提供了与客户相关的API调用方法
   - 包含获取客户会员关系的API调用：`getCustomerMemberRelations`

5. **会员数据类型**：`src/types/member.ts`
   - 定义了会员相关的数据类型和接口

## 实现方案

根据需求和现有系统分析，提出以下实现方案：

### 方案一：客户列表中添加会员计数和快速查看功能

1. **增强客户列表**：
   - 在客户列表中添加"关联会员数"列，显示每个客户关联的会员数量
   - 添加"查看会员"按钮，点击后显示该客户的会员列表弹窗

2. **实现会员列表弹窗**：
   - 创建新组件 `src/components/CustomerManagement/CustomerMembersDialog.vue`
   - 弹窗中显示会员列表，包括基本信息和操作按钮

3. **数据流程**：
   - 客户列表加载时，获取每个客户的会员数量
   - 点击"查看会员"按钮时，调用API获取该客户的会员列表
   - 在弹窗中展示会员信息，支持基本的筛选和搜索

### 方案二：客户列表中添加可展开的会员子表格

1. **实现可展开行**：
   - 利用Element Plus的表格展开行功能
   - 点击展开图标时，显示该客户关联的会员列表

2. **子表格实现**：
   - 创建新组件 `src/components/CustomerManagement/CustomerMembersSubTable.vue`
   - 在展开行中显示会员子表格

3. **数据流程**：
   - 点击展开图标时，动态加载该客户的会员数据
   - 展示会员基本信息，提供简单的操作按钮

### 方案三：增强客户详情页的会员关系标签页

1. **优化现有详情页**：
   - 改进客户详情页中的会员关系标签页
   - 增加更多的筛选和操作功能

2. **添加快速入口**：
   - 在客户列表中添加"会员数量"列和"查看会员"快捷按钮
   - 点击按钮直接跳转到客户详情页的会员关系标签页

## 推荐方案

综合考虑用户体验、开发复杂度和系统一致性，**推荐采用方案二：客户列表中添加可展开的会员子表格**。

理由：
1. 用户可以在不离开客户列表页面的情况下查看会员信息，提高操作效率
2. 可展开行是Element Plus的标准功能，与系统UI风格一致
3. 按需加载会员数据，不会影响客户列表的初始加载性能
4. 实现相对简单，不需要大幅修改现有代码结构

## 实现步骤

1. **修改客户列表页面**：
   - 添加表格的可展开行配置
   - 实现展开行的模板，引入会员子表格组件

2. **创建会员子表格组件**：
   - 实现会员列表的展示
   - 添加必要的操作按钮和功能

3. **扩展客户Store**：
   - 添加按客户ID缓存会员数据的功能
   - 优化数据加载逻辑，避免重复请求

4. **增加国际化支持**：
   - 在语言文件中添加新的翻译条目
